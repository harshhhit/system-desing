SHA-256 hash tool

Type your chosen password below. Copy the hex string into PASSWORD_HASH in login.html.

—

Hashing happens entirely in your browser. Nothing is sent anywhere. No trailing newline is added, so it matches the login page exactly.

Prefer a one-liner?

Browser console (any page):

crypto.subtle.digest('SHA-256', new TextEncoder().encode('YOUR_PASSWORD'))
  .then(b => console.log([...new Uint8Array(b)].map(x => x.toString(16).padStart(2,'0')).join('')));

Terminal (macOS / Linux) — note -n / %s to avoid a trailing newline:

printf %s 'YOUR_PASSWORD' | shasum -a 256
echo -n 'YOUR_PASSWORD' | sha256sum
