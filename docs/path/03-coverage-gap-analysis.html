Coverage Gap Analysis & Prompts

What the site is missing, grouped by topic, each with a ready-to-paste prompt to close the gap.

How this list was built

Audited on 2026-09-19 by grepping every page under docs/ for ~30 core system-design keywords, then cross-checking assets/sitemap.js and assets/pages.js for a dedicated page on each — a passing mention inside another note (e.g. "use a cache here") doesn't count as coverage. The list below is only topics with zero dedicated page anywhere in the site. A link-integrity pass (every sitemap.js/pages.js href resolves, every PAGE_CONFIG id matches, every page carries the access gate) also ran and found nothing broken — the gaps here are content gaps, not wiring bugs.

Node.js is not installed in this environment

This page was added by hand-copying _TEMPLATE-page.html and adding matching entries to pages.js / sitemap.js, because node scripts/regen-sidebars.js couldn't run here (node: command not found). The page works today — site-header.js fills the sidebar/heading live from sitemap.js/pages.js at runtime. What's still outstanding: the baked no-JS <nav> copies in every other page under docs/ don't yet include a link to this page, and --check hasn't been re-run. Once node is available, run node scripts/regen-sidebars.js && node scripts/regen-sidebars.js --check once — it's idempotent and will simply bake this page in and confirm a clean 0.

Already solid

These 13 sidebar sections have real depth and don't need new top-level coverage — gaps inside them are called out per-topic below instead of repeated here.

  • Kubernetes — control plane, data plane, RBAC, storage, leader election (12 pages)
  • Authentication — login flow, password hashing, OAuth/social login
  • Front-End — rendering models, SSR/CSR, GraphQL vs REST, cookies/JWT
  • Database — the single deepest section: foundations → SQL → modeling → transactions → query plans → distributed fundamentals → security → scaling → connection pooling → backup/DR → observability (20 pages)
  • Distributed Systems / Distributed Database — replication mechanics, PACELC, WAL vs binlog, replication lag
  • Messaging & Queues — SQS deep-dive plus a runnable multiprotocol starter project
  • Storage, Web Servers, Dev Principles, Planning & Roadmap, Project Walkthroughs, Miscellaneous — solid single-topic coverage each

What's missing — and the prompt to close each gap

Grouped into clusters that map to either a brand-new sidebar section or a clear extension of an existing one. Each prompt is written to be pasted as-is into a Claude Code session in this repo — it names the add-page skill and the exact section, so the page comes out wired correctly the first time (template copied, PAGE_CONFIG id set, pages.js + sitemap.js entries added, regen-sidebars.js run and --checked) without a second pass.
