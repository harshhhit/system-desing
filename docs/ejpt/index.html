eJPT Course: Basic to Advanced

A free, hands-on study path for INE's eJPT certification (rebuilt March 2026: 45 questions, 48 hours) — lab setup, recon, exploitation, privilege escalation, pivoting and web app attacks, module by module.

About the eJPT exam

The eJPT is a 48-hour, open-book, fully hands-on exam: 45 questions answered by actually attacking a lab network, 70% to pass. INE rebuilt it on 31 March 2026 (35 → 45 questions, more web app and recon content), so ignore older guides that say 35 questions or 72 hours. The voucher costs about $249, or comes bundled with INE's annual subscription. Every learning resource in this course is free — the exam voucher is the only thing you pay for.

💡 How to use this course

Go module by module. For each one, watch the videos, then do every lab task before moving on — the exam rewards doing, not watching. Keep one notes file (Obsidian or CherryTree) with a section per domain and paste every command that worked. Total effort: roughly 8–10 weeks at 1.5–2 hours a day.

The modules

Work through them in order. Each is its own page with videos, commands and a tickable lab checklist.

  1. Module 0 — Lab Setup (Week 1, 2–3 days) — build one attacker VM and three vulnerable targets on an isolated host-only network.
  2. Module 1 — Foundations (Week 1–2) — read a packet, a subnet and a Linux/Windows box like an attacker.
  3. Module 2 — Assessment Methodologies (Week 3–4) — recon, scanning and enumeration until they're automatic.
  4. Module 3 — Host & Network Penetration Testing (Week 4–6) — turn enumeration findings into shells.
  5. Module 4 — Post-Exploitation, Privilege Escalation & Pivoting (Week 6–7) — loot, escalate, and pivot to hidden subnets.
  6. Module 5 — Web Application Penetration Testing (Week 7–8) — Burp Suite plus the core OWASP bugs.
  7. Module 6 — Exam Readiness (Week 8–10) — timed practice, cheat sheet, book and sit the exam.
