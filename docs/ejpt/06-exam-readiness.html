Module 6 — Exam Readiness

Timed practice on TryHackMe and VulnHub, a 6-hour self-made mock with a pivot, the one-screen exam-day cheat sheet, and the exam tips — then book the voucher.

Goal

Put the pieces together under time pressure, then book the exam.

Practice targets (free, in order of realism)

  • TryHackMe free eJPT-style rooms: Ignite, Startup, RootMe, Blog, Erit Securus I.
  • More free TryHackMe rooms: Vulnversity, Blue, Kenobi, Steel Mountain (guided web + network boxes, no subscription needed).
  • VulnHub boxes you download and attack end-to-end: Kioptrix series, then a multi-host one for pivoting practice.
  • A free practice question bank such as open-exam-prep.com/study-guides/ejpt to drill the question style.

💡 Mock exam (do this ~1 week before)

Pick a VulnHub network you have never seen, give yourself 6 hours, and produce findings for each host: open ports, service versions, the exploit used, the shell obtained, and any pivot. If you can do that comfortably, you are ready.

Exam-day cheat sheet

Keep this one screen away.

# 1. Map the whole network FIRST
nmap -sn <range>                      # live hosts
nmap -p- --min-rate 3000 <host>       # all ports
nmap -sC -sV -p <open> <host>         # services + versions

# 2. Enumerate every service before exploiting anything
enum4linux -a <host>; smbclient -L //<host> -N
gobuster dir -u http://<host> -w <wordlist>
searchsploit <service> <version>

# 3. Exploit, then always check for a second NIC (pivot!)
ip a; ifconfig; arp -a               # on every shell you get
run autoroute -s <inner-subnet>      # Meterpreter pivot

# 4. Answer questions as you go — it is open book, 48 hours

Exam tips

  • It is open-book and unproctored — your notes file is your biggest asset. Keep pasting working commands into it from Module 0 onward.
  • You get two attempts; a failed retake must be used within 14 days, so schedule with that buffer in mind.
  • Read every question fully before touching the lab; many answers come from enumeration you would do anyway.
  • When stuck, go back to enumeration. On this exam the answer is almost always a service or version you have not looked at closely enough.
  • Reference: sample exam writeup (91%, 4.5h) · eJPT cheat sheet repo.
